
# Password Strength Checker 🔐

## About
A simple Python project that evaluates
password strength using different criteria.

## Features
- Checks password length
- Checks uppercase and lowercase letters
- Checks numbers
- Checks special characters
- Classifies password strength

## Technologies Used
- Python 3

## How to Run
1. Install Python.
2. Download this repository.
3. Open the terminal.
4. Run: python password_checker.py
